## ARRAY – NOTES

### Definition

An array is a collection of elements of the same data type stored in continuous memory locations.
All elements are accessed using a single array name with the help of an index.

---

### Example

`int arr[5] = {10, 20, 30, 40, 50};`

* `arr` → array name
* `5` → size of array
* `10, 20, 30, 40, 50` → elements

---

### Indexing

Array indexing starts from **0**.

* First element → `arr[0]`
* Second element → `arr[1]`
* Last element → `arr[size-1]`

---

### Features of Array

* Stores multiple values in one variable
* All elements are of same data type
* Memory is allocated in contiguous order
* Fixed size
* Fast access using index

---

### Advantages of Array

* Easy to use and understand
* Faster access to elements
* Reduces number of variables
* Efficient for searching and sorting
* Better performance

---

### Disadvantages of Array

* Fixed size (cannot grow or shrink)
* Insertion and deletion are difficult
* Memory wastage may occur
* Cannot store different data types

---

### Applications of Array

* Storing student marks
* List of items
* Matrix representation
* Searching and sorting data
* Used in many programs and applications

---

### Important Points

* Array uses index-based access
* Index starts from 0
* Size must be declared before use
