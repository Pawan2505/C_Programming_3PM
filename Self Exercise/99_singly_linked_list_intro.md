📝 This question explains:

What a Singly Linked List is

Structure of a node (data + next pointer)

How nodes are connected in one direction

Answer (Simple Explanation):
A Singly Linked List is a linear data structure where each node contains:

Data

Pointer (next) that stores the address of the next node

The last node’s next pointer stores NULL, which indicates the end of the list.
Traversal is possible only in forward direction.
